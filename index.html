Deployed apps

Two full-stack apps I built and put online.

  1. 01

    Job Pipeline Platform

    Visit the live app

    A job-search tool that finds postings, tailors a resume and cover letter to each one, and tracks applications.

    How it works
    • It searches about a dozen job boards and applicant-tracking systems, filters postings against the user's resume, and writes a tailored resume and cover letter for each one.

Running on my home server

Systems I build and run myself. The source is in private repos, so each one gets a short write-up instead of a link.

  1. 01

    Home server platform

    One always-on machine running about two dozen self-hosted services, with local names, DNS, monitoring and scheduled deploys.

    How it works
    • It's a repurposed gaming laptop running Ubuntu Server, with a GPU for local AI models and a fixed LAN address. Tailscale handles remote access.
    • Pi-hole is the network's DNS and DHCP server. A reverse proxy gives each service a local name, and a Cloudflare Tunnel exposes only the few apps that need to be public.
    • Nextcloud syncs phone photos, Vaultwarden stores passwords, Samba shares files with Windows, and a Homepage dashboard links it all together.
    • Uptime Kuma watches about twenty services and gets a heartbeat from every cron job, so a job that quietly stops raises an alert.
    • Every project repo has a deploy cron that pulls from GitHub every five minutes. A watchdog alerts me if one of those cron lines disappears.
    • Docker
    • Pi-hole
    • Nginx Proxy Manager
    • Tailscale
    • systemd
  2. 02

    YouTube content pipelines

    Automated video production. A topic or source goes in, and a finished vertical or long-form video comes out and uploads on a schedule with no manual steps.

    How it works
    • Each pipeline runs end to end on a schedule. It picks a topic or source, writes the script or finds the best moments, adds voice, captions and footage, renders with FFmpeg and uploads through the YouTube API.
    • A local language model writes the cheap first draft, then Claude polishes it, ranks options and writes titles, so most of the work costs nothing. One helper tries the cheaper provider first and falls back to the other.
    • Clips only come from a verified permission list or public-domain material. New candidates are flagged for manual review instead of being added automatically.
    • Every video passes a content-quality check before upload, and the description discloses AI use.
    • A shared GPU lock keeps pipelines from colliding. Upload slots are claimed in a state file so two runs never publish at the same second. Every run sends a heartbeat, so a silent failure raises an alert.
    • I tested several local models. Forcing JSON mode helped short calls and hurt long-form prose, so the code uses it only where it helps.
    • Python
    • Ollama
    • faster-whisper
    • FFmpeg
    • YouTube API
  3. 03

    Ops Chat

    A chat assistant and self-healing monitor for the server.

    How it works
    • You can ask it how the disk is doing or whether last night's pipeline ran. A local model calls tools for disk, containers, DNS stats, monitors, pipeline logs and incident history.
    • A background monitor restarts containers that go down and guards against memory leaks. It also watches deploys, the tunnel, the GPU, disk space and cron lines.
    • It emails a daily digest of incidents and each pipeline's last run, and flags any pipeline whose uploads suddenly drop to zero.
    • Tools are plain Python functions with a schema, so adding one takes a few lines and a self-check.
    • Python
    • FastAPI
    • Ollama
    • Function calling
  4. 04

    YouTube Manager Agent

    Analytics and optimization for all of my YouTube channels.

    How it works
    • Phase one collects analytics daily, builds a profile of each channel's niche, and emails one plain-language weekly report.
    • Phase two edits titles and tags on underperforming videos. It is limited per channel and per week, has a cooldown, and logs every change.
    • Each edit is compared against untouched control videos. If the edited video does worse, it is rolled back automatically.
    • Each channel can run fully automatic or require approval, and one token file per channel works as its on/off switch.
    • Python
    • YouTube APIs
    • Docker
    • LLM
  5. 05

    Finance tracker

    Personal finance automation. Bank alert emails become categorized transactions on a custom dashboard.

    How it works
    • A parser reads bank alert emails, pulls out the details with per-bank patterns, and posts them to a self-hosted Firefly III ledger.
    • It de-duplicates by message ID, merges duplicate alerts for the same payment, and retries failures instead of dropping them.
    • A custom dashboard shows spending and net worth, and tracks money owed and lent between friends.
    • Python
    • Firefly III
    • FastAPI
    • IMAP
  6. 06

    Sports analytics bots

    Two bots that model match outcomes and flag where bookmaker odds disagree with the model.

    How it works
    • Each is a four-container stack: ingestion, analysis, notification and a database.
    • One covers football leagues with a heuristic edge model. The other covers esports with an ELO model.
    • Odds come from public feeds, filtered to an allowlist of bookmakers. An integrity check sends a digest when the data looks wrong, and a dashboard shows predictions and results.
    • They only analyze and alert. They never place anything.
    • Python
    • PostgreSQL
    • Docker
    • Scrapers
